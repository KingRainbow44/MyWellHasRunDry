# scripts

scripts are part of iterative design

## Dictionary

- `q_xxxxxx` - A quest-related script
- `g_[name]` - A gadget/entity script, usually for controlling behaviors
- `b_[name]` - A behavior script, usually for controlling other world logic
- `group_[scene]_xxxxx` - A group of objects in a scene
  - A `scene` refers to a specific area in the game world
  - `xxxxx` is a unique identifier for the group

### For Quests

- `1xxxxx` - A common quest assigned to all players; related to the story
- `2xxxx` - A quest assigned to the `Warevara` faction
- `3xxxx` - A quest assigned to the `Arbysid` faction
- `4xxxx` - A quest assigned to the `Korvax` faction
  - aka the `Jesus Dynasty`
- `5xxxx` - A quest assigned to the `Karunia` faction
- `9xxxxx` - A common quest assigned to all players; related to the world
- `8xxxxx` - A common quest assigned to all players; miscellaneous quests
